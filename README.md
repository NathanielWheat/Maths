# Projects

2D SUVAT Calculator

A python based calculator that uses user input values in order to calculate all the suvat values for a 2d projectile.
- Accepts any 3 or more known values
- Calculates the remaining variables
- Supports unknown value input
- Designed to handle any 2d suvat calculation.

Projectile Motion Calculator

A python based calculator that takes user input for the initial launch velocity as well as launch angle and calculates things such as max height, range and calculates the position of the projectile at 0.1 second intervals.
Utilises the matplotlib module in order to create a graph to visualise each point of the projectile.
- Accepts angles in Degrees
- Can handle projectile motion at any initial height
- Only calculates for a projectile reaching ground level (y = 0)

Probability - Coin flip

Using foundational probability skills through python to find out the probability of landing on heads 5 times in a row atleast once
- Limited flexibility
- Currently demonstrates the use of an analytical method (Mathematical based) and the Monte Carlo method (simulation based)
